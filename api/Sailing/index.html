    Sailing¶

    srs::api::Sailing / srs.sailing

    Boat state, helm and sail controls, the cargo hold, and the port-task notice board for the Sailing skill.

    A boat is its own small world with its own scene, separate from the main map. The boat you are standing on is reported by boat(); every boat in view (yours, other players', and static moored ships) is reported by boats(). Boat positions are in main-world tiles.

    Steering works by sending an absolute heading from 0 to 15 (16 compass points: 0 = south, 4 = west, 8 = north, 12 = east). You do not click the on-screen markers yourself; setHeading / steerTowards send the bearing for you. The boat then turns toward it one step at a time, so the reported heading lags the command by a few seconds.

    Interface-driven calls (sails, speed, board, cargo hold) operate on panels that must already be rendered. The API never opens side tabs for you; open the right tab from your script first, otherwise these calls return false.

    Methods¶

    Boat state¶

    Description C++ Lua
    Boat the local player is aboard (nil/nullopt if none) Sailing::boat(ctx) → optional<BoatInfo> srs.sailing.boat() → table\|nil
    Every boat in the scene, including yours Sailing::boats(ctx) → vector<BoatInfo> srs.sailing.boats() → table
    Is the local player on a boat Sailing::isOnBoat(ctx) → bool srs.sailing.isOnBoat() → bool
    Raw "operating a facility" value (varbit 19105) Sailing::lockedFacility(ctx) → int32 srs.sailing.lockedFacility() → int
    Is the player at the helm (lockedFacility == 3) Sailing::isAtHelm(ctx) → bool srs.sailing.isAtHelm() → bool

    lockedFacility is non-zero while you operate any boat facility; 3 is the value seen at the helm.

    Helm and steering¶

    Description C++ Lua
    Take the wheel (op 1 on your boat's helm) Sailing::interactHelm(ctx) → bool srs.sailing.interactHelm() → bool
    Heading (0..15) from one tile to another; -1 if identical Sailing::headingTo(fromX, fromY, toX, toY) → int32 srs.sailing.headingTo(fromX, fromY, toX, toY) → int
    Unit direction vector of a heading (+y = north) Sailing::headingVector(heading) → pair<double,double> —
    Command an absolute heading (0..15). Needs the helm Sailing::setHeading(ctx, heading) → bool srs.sailing.setHeading(heading) → bool
    Steer toward a world tile Sailing::steerTowards(ctx, tileX, tileY) → bool srs.sailing.steerTowards(tileX, tileY) → bool
    • setHeading returns false for a heading outside 0..15, when you are not aboard a boat, or when the boat cannot be projected onto the screen. It must be called while you are at the helm (see isAtHelm).
    • steerTowards computes headingTo(boat, target) and sends it. It returns true without sending anything when the boat is already at the target tile or already pointing the right way, so it is safe to call every pulse. It returns false when you are not aboard.
    • interactHelm returns false if no helm is found on your boat.

    Sails and speed¶

    Description C++ Lua
    Set / unset sails (one toggle) Sailing::toggleSails(ctx) → bool srs.sailing.toggleSails() → bool
    Lower speed one step Sailing::lowerSpeed(ctx) → bool srs.sailing.lowerSpeed() → bool
    Raise speed one step Sailing::raiseSpeed(ctx) → bool srs.sailing.raiseSpeed() → bool

    Setting sails from a stop goes straight to top speed. All three need the Sailing side tab open on its Facilities sub-tab (interface 937, component 25); they return false when that panel is not rendered. true means the click was dispatched, not that the boat changed state; read boat().speed to confirm.

    Cargo hold¶

    Description C++ Lua
    Op 1 on your boat's cargo hold Sailing::interactCargoHold(ctx) → bool srs.sailing.interactCargoHold() → bool
    Is the cargo-hold interface (943) open Sailing::isCargoHoldOpen(ctx) → bool srs.sailing.isCargoHoldOpen() → bool
    Stacks in the open hold Sailing::cargoHoldItems(ctx) → vector<CargoItem> srs.sailing.cargoHoldItems() → table
    Withdraw the stack of an item id Sailing::withdrawCargo(ctx, itemId) → bool srs.sailing.withdrawCargo(itemId) → bool

    Using the hold while carrying cargo deposits it directly; with nothing to deposit it opens the cargo-hold interface. cargoHoldItems is empty while the interface is closed. withdrawCargo returns false if the item is not in the open hold or its cell is not rendered.

    Port tasks¶

    Description C++ Lua
    Occupied task slots Sailing::portTasks(ctx) → vector<PortTaskSlot> srs.sailing.portTasks() → table
    Task slots your Sailing level allows (1..5) Sailing::taskCapacity(ctx) → int32 srs.sailing.taskCapacity() → int

    taskCapacity is derived from base Sailing level: 1 / 7 / 28 / 56 / 84 give 1 / 2 / 3 / 4 / 5 slots. It is the level cap only; any additional unlocked slots are not counted.

    Notice board and task offers¶

    Description C++ Lua
    Is the notice board (941) open Sailing::isBoardOpen(ctx) → bool srs.sailing.isBoardOpen() → bool
    Cards on the open board Sailing::boardOffers(ctx) → vector<BoardOffer> srs.sailing.boardOffers() → table
    Open a card's task popup by dbrow Sailing::openOffer(ctx, dbrow) → bool srs.sailing.openOffer(dbrow) → bool
    Is the task-info popup (942) open Sailing::isOfferOpen(ctx) → bool srs.sailing.isOfferOpen() → bool
    Parsed contents of the open popup Sailing::offerDetails(ctx) → optional<OfferDetails> srs.sailing.offerDetails() → table\|nil
    Accept the open offer Sailing::acceptOffer(ctx) → bool srs.sailing.acceptOffer() → bool
    Back from the popup to the board Sailing::backFromOffer(ctx) → bool srs.sailing.backFromOffer() → bool
    Close the board / popup Sailing::closeBoard(ctx) → bool srs.sailing.closeBoard() → bool
    • boardOffers is empty while the board is closed. Offers are identified by dbrow; pass that to openOffer.
    • acceptOffer returns false without clicking when every task slot you are allowed is already in use (the server would refuse it silently), and when the popup is not open.
    • backFromOffer returns false when the popup is not open.
    • closeBoard presses Escape and returns true immediately if neither the board nor the popup is open.

    Types¶

    BoatInfo¶

    Returned by boat() / boats(). In Lua each boat is a plain table with these fields.

    Field Type Notes
    id int Boat id (also the key of its own scene)
    x, y int World tile
    plane int Plane (currently always 0)
    fineX, fineY int World position in 1/128-tile units (sub-tile precision)
    heading int Direction the boat is facing now, 0..15; -1 = unreadable
    orientation int Facing in 0..2047 units (128 per heading step); -1 = unreadable
    speed int Fine units per tick (128 = 1 tile/tick); 0 at rest
    sizeX, sizeY int The boat's own scene size in tiles. An upper bound on the hull; the long side lies along the heading. Useful for steering clear of other boats
    ownerType int 0 = not a player's boat (static or moored ship, solid), 1 = another player's boat (you sail through it), 2 = yours, -1 = unreadable
    configId int Boat type id
    isLocal bool The local player is aboard this boat

    BoardOffer¶

    One card on the open notice board. In Lua: tables with the fields marked below.

    Field Type Lua Notes
    card int yes 0-based card position (row-major)
    dynIndex int no Internal child index used for the click
    dbrow int yes Task row id; pass to openOffer. -1 if unreadable
    name string yes Card title with colour tags removed, e.g. "Pandemonium steel delivery"
    level int yes Sailing level printed on the card
    levelMet bool yes Your base Sailing level is at least level
    badgeSprite int yes Requirement-badge sprite id (7107 / 7108); diagnostic only
    isCourier bool yes Name ends in "delivery" (bounties end in "bounty")

    Note

    dbrow is the task's board row. It is not the same number as PortTaskSlot.taskId, which is the id stored in your task slot varbits.

    OfferDetails¶

    Parsed from the open task-info popup. In Lua: a table with the same fields.

    Field Type Notes
    name string Task title
    level int Sailing level required
    cargo string Cargo item name
    location string Where the cargo is collected
    destination string Where it is delivered
    quantity int Amount of cargo
    description string Remaining flavour text (lines joined with \n)

    CargoItem¶

    Field Type Notes
    slot int Cell index in the hold grid
    itemId int Item id
    qty int Stack quantity

    PortTaskSlot¶

    Returned by portTasks(); only occupied slots (task id non-zero) appear.

    Field Type Notes
    slot int 0..4
    taskId int Task id held in that slot (see the note under BoardOffer)
    cargoTaken int Cargo collected so far
    cargoDelivered int Cargo delivered so far

    Example¶

    using namespace srs::api;
if (auto b = Sailing::boat(ctx)) {
    // Sail toward a world tile; safe to call every pulse.
    if (Sailing::isAtHelm(ctx)) {
        Sailing::steerTowards(ctx, 3050, 3210);
    } else {
        Sailing::interactHelm(ctx);
    }
}

    local TARGET_X, TARGET_Y = 3050, 3210

function script.pulse()
    local boat = srs.sailing.boat()
    if not boat then return end

    if not srs.sailing.isAtHelm() then
        srs.sailing.interactHelm()
        return
    end

    -- Point at the destination (no-op if already pointing there).
    srs.sailing.steerTowards(TARGET_X, TARGET_Y)

    -- List static (solid) ships in view.
    for _, other in ipairs(srs.sailing.boats()) do
        if not other.isLocal and other.ownerType == 0 then
            log.info(("static ship at %d,%d size %dx%d"):format(
                other.x, other.y, other.sizeX, other.sizeY))
        end
    end
end

-- Taking a task from an open notice board:
if srs.sailing.isBoardOpen() and #srs.sailing.portTasks() < srs.sailing.taskCapacity() then
    for _, offer in ipairs(srs.sailing.boardOffers()) do
        if offer.levelMet and offer.isCourier then
            srs.sailing.openOffer(offer.dbrow)
            break
        end
    end
end
if srs.sailing.isOfferOpen() then
    local d = srs.sailing.offerDetails()
    if d then log.info(d.name .. ": " .. d.cargo .. " x" .. d.quantity) end
    srs.sailing.acceptOffer()
end

    Open the right tab first

    toggleSails, lowerSpeed and raiseSpeed need the Sailing side tab open on Facilities. The board, popup and cargo-hold calls need their interface open. None of these calls open a tab or interface for you; they return false when the panel is not rendered.

    A returned true means dispatched

    Every action call returns true when the click or packet was sent. It does not confirm the game accepted it. Poll boat(), portTasks(), cargoHoldItems() or the is*Open calls to confirm, and throttle repeated calls rather than firing one every pulse.

    Heading lags the command

    setHeading sets the boat's target bearing. The boat turns one step at a time, so boat().heading takes a few seconds to catch up. Do not treat a mismatch as a failed command.
