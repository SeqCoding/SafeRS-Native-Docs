    GroundItem¶

    srs::api::GroundItem / srs.grounditem

    Read-only enumeration of dropped items in every loaded scene, all 4 planes. The nearest* finders and loot(id) / lootByName use Chebyshev tile distance from the local player.

    Methods¶

    Method C++ Lua
    All ground items GroundItem::all(ctx) → vector<GroundItemEntry> srs.grounditem.all() → table
    By id GroundItem::byId(ctx, id) → vector<GroundItemEntry> srs.grounditem.byId(id) → table
    By name GroundItem::byName(ctx, name) → vector<GroundItemEntry> srs.grounditem.byName(name) → table
    Nearest (any) GroundItem::nearest(ctx) → optional<GroundItemEntry> srs.grounditem.nearest() → GroundItemEntry \| nil
    Nearest by id GroundItem::nearestById(ctx, id) → optional<GroundItemEntry> srs.grounditem.nearestById(id) → GroundItemEntry \| nil
    Nearest by name GroundItem::nearestByName(ctx, name) → optional<GroundItemEntry> srs.grounditem.nearestByName(name) → GroundItemEntry \| nil
    Loot nearest pile of id GroundItem::loot(ctx, id) → bool srs.grounditem.loot(id) → bool
    Loot nearest pile by name GroundItem::lootByName(ctx, name) → bool srs.grounditem.lootByName(name) → bool
    Loot exactly this pile GroundItem::loot(ctx, entry) → bool srs.grounditem.loot(entry) → bool
    Examine GroundItem::examine(ctx, target) → bool srs.grounditem.examine(target) → bool

    Name lookups match the item's in-game display name (case- and whitespace-insensitive substring). byName("bones") returns all bone variants on the floor.

    loot / lootByName route through Interact (always-on spoof + engine action dispatch) using MenuAction::GROUND_ITEM_FIRST_OPTION (opcode 20). Returns false if no match, the tile isn't visible on screen, or the spoofer can't inject.

    loot(id) / lootByName(name) ignore ownership

    Both take the nearest matching pile (Chebyshev distance from you), whoever it belongs to. To loot only your own drops, pick an entry yourself (filter on isMine) and pass it to loot(entry).

    loot(entry) loots exactly that pile. It re-reads the live scene and matches by item id + tile + plane + ownership (preferring the same quantity), so a stale entry never fires at a different player's pile on the same tile. Returns false if the pile is gone. The Lua loot accepts either an item id or a GroundItemEntry.

    Types¶

    GroundItemEntry (read-only):

    Field Type Notes
    id int32
    quantity int32
    tileX int32
    tileY int32
    plane int32
    ownership int32 Server-reported owner class, see constants below
    isMine bool true when the item counts as your loot (see below)

    Constants¶

    Ownership values mirror RuneLite's TileItem.OWNERSHIP_* and are sent by the server with every ground item:

    Meaning C++ Lua
    Map spawn / nobody srs::api::kOwnershipNone (0) srs.grounditem.Ownership.None
    Dropped by or rewarded to you srs::api::kOwnershipSelf (1) srs.grounditem.Ownership.Self
    Another player srs::api::kOwnershipOther (2) srs.grounditem.Ownership.Other
    Your ironman group srs::api::kOwnershipGroup (3) srs.grounditem.Ownership.Group

    Use isMine, not ownership == Self

    On an account that is not a group ironman the server reports other players' drops as Group (both sides have group id -1 — the same quirk RuneLite works around in its Ground Items plugin). isMine is true for Self, and for Group only while the local account type (varbit 1777) is a group-ironman variant, so it is the right test for "loot my items only".

    Note

    Items you have not received an OBJ_ADD for — other players' drops before they become public — are not in the pile at all, so they never appear in all(). Ownership is written once when the pile entry is created; no packet handler we have traced rewrites it later.

    Example¶

    using namespace srs::api;
if (auto bones = GroundItem::nearestByName(ctx, "Bones")) {
    GroundItem::loot(ctx, bones->id);
}

    local bones = srs.grounditem.nearestByName("Bones")
if bones then
    if srs.grounditem.loot(bones.id) then
        log.info(("looting bones at %d, %d"):format(bones.tileX, bones.tileY))
    end
end

    Loot only your own drops (ironman-safe) — pick the nearest isMine pile yourself, then loot exactly that one:

    using namespace srs::api;
auto me = Player::position(ctx);
const GroundItemEntry* best = nullptr;
int bestDist = INT_MAX;
auto seeds = GroundItem::byName(ctx, "seed");
for (const auto& g : seeds) {
    if (!g.isMine || g.plane != me.plane) continue;   // skip other players' / spawned items
    int d = std::max(std::abs(g.tileX - me.x), std::abs(g.tileY - me.y));
    if (d < bestDist) { bestDist = d; best = &g; }
}
if (best) GroundItem::loot(ctx, *best);

    local me = srs.player.position()
local best, bestDist
for _, g in ipairs(srs.grounditem.byName("seed")) do
    if g.isMine and g.plane == me.plane then
        local d = math.max(math.abs(g.tileX - me.x), math.abs(g.tileY - me.y))
        if not bestDist or d < bestDist then best, bestDist = g, d end
    end
end
if best then srs.grounditem.loot(best) end
