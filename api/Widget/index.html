    Widget¶

    srs::api::Widget / srs.widget

    Read-only inspection of the OSRS interface tree, plus a generic click. Widgets are identified by (groupId, childId) — matches RuneLite's WidgetID encoding.

    State / lookup¶

    Method C++ Lua
    IfTypeManager warmed up Widget::isReady(ctx) → bool srs.widget.isReady() → bool
    Find by (group, child) Widget::find(ctx, g, c) → optional<WidgetSnapshot> srs.widget.find(g, c) → WidgetSnapshot \| nil
    All in group Widget::group(ctx, g) → vector<WidgetSnapshot> srs.widget.group(g) → table
    Dynamic children Widget::dynamicChildren(ctx, g, c) → vector<WidgetSnapshot> srs.widget.dynamicChildren(g, c) → table
    RuneLite-style label Widget::label(g, c) → string srs.widget.label(g, c) → string

    Dynamic children¶

    dynamicChildren enumerates the runtime-allocated IfTypes held in the parent's vector at IfType+0xB58. This is where inventory slots, bank items, dialogue options, etc. live; they don't appear in group() (which only walks the static Components array).

    Each entry's dynIndex carries its array slot, parentGroupId/parentChildId point to (g, c), and text typically holds the option label or item-derived caption.

    label¶

    Returns the most informative form available, in priority order:

    1. "Inventory.ITEMS" — exact InterfaceID nested constant
    2. "INVENTORY[0]" — group name + child index
    3. "149.0" — numeric fallback

    Visibility¶

    Method C++ Lua
    Interface rendering Widget::isOpen(ctx, g) → bool srs.widget.isOpen(g) → bool
    Drawn last frame Widget::isVisible(ctx, g, c) → bool srs.widget.isVisible(g, c) → bool
    Hidden (or ancestor hidden) Widget::isHidden(ctx, g, c) → bool srs.widget.isHidden(g, c) → bool

    isVisible returns true iff the engine actually drew the widget last frame (hook-snapshot path). The renderer skips any widget whose own or any ancestor's Hidden flag is set, so this matches RuneLite's recursive Widget.isHidden() semantics for free.

    Defaults on lookup-miss mirror the Java helpers exactly:

    • isVisible(g, c) → false when widget can't be found
    • isHidden(g, c) → true when widget can't be found

    Hit-test¶

    Method C++ Lua
    Hit-test screen point Widget::atPoint(ctx, sx, sy) → optional<WidgetSnapshot> srs.widget.atPoint(sx, sy) → WidgetSnapshot \| nil
    Currently hovered Widget::hovered(ctx) → optional<WidgetSnapshot> srs.widget.hovered() → WidgetSnapshot \| nil

    Rect fields are absolute screen coords for these two methods.

    Click¶

    Method C++ Lua
    Click action Widget::click(ctx, g, c, action) → bool srs.widget.click(g, c, action) → bool

    Click a named action on a widget. Resolves the widget's absolute screen rect via the live IfRender capture, picks a random point in the rect, and routes through Interact (always-on spoof + DoAction).

    For inventory slots prefer Inventory::interact — same mechanism, narrower API.

    Types¶

    WidgetSnapshot (read-only):

    Field Type Notes
    groupId int32
    childId int32
    parentGroupId int32 -1 if no parent
    parentChildId int32 -1 if no parent
    dynIndex int32 -1 = static child; ≥ 0 = dynamic-child slot
    x, y int32 Parent-relative for find/group; absolute screen for atPoint/hovered
    width, height int32
    hidden bool
    itemId int32 -1 if not an item-bearing widget
    itemQty int32
    spriteId int32 -1 if no sprite
    name string Tooltip name baked into the IfType
    text string Visible label content
    targetVerb string Spell/use prefix shown on cursor while staging
    actions vector Right-click options (first 5 inline; overflow not fetched)
    dynChildCount uint64 Use dynamicChildren(g, c) to walk them
