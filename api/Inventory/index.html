    Inventory¶

    srs::api::Inventory / srs.inventory

    Read-only view of the player's backpack (28 slots) plus item-action helpers. Action calls route through Interact (always-on spoof + DoAction).

    Methods¶

    Method C++ Lua
    Snapshot all slots Inventory::all(ctx) → vector<InventoryItem> srs.inventory.all() → table
    One slot (0..27) Inventory::at(ctx, slot) → optional<InventoryItem> srs.inventory.at(slot) → InventoryItem \| nil
    Contains by id Inventory::contains(ctx, id) → bool srs.inventory.contains(id) → bool
    Contains by name Inventory::contains(ctx, name) → bool srs.inventory.contains(name) → bool
    Count by id Inventory::count(ctx, id) → int32 srs.inventory.count(id) → int
    Count by name Inventory::count(ctx, name) → int32 srs.inventory.count(name) → int
    First slot by id Inventory::firstSlot(ctx, id) → int32 srs.inventory.firstSlot(id) → int
    First slot by name Inventory::firstSlot(ctx, name) → int32 srs.inventory.firstSlot(name) → int
    Empty slots count Inventory::emptySlots(ctx) → int32 srs.inventory.emptySlots() → int
    Full Inventory::isFull(ctx) → bool srs.inventory.isFull() → bool
    Empty Inventory::isEmpty(ctx) → bool srs.inventory.isEmpty() → bool

    Name lookups match the item's in-game display name (case- and whitespace-insensitive substring). contains("prayer potion") matches all 4 dose variants. firstSlot returns -1 if the item isn't present.

    Actions¶

    Method C++ Lua
    Click action on slot Inventory::interact(ctx, slot, action) → bool srs.inventory.interact(slot, action) → bool
    Click by id Inventory::interactById(ctx, id, action) → bool srs.inventory.interactById(id, action) → bool
    Click by name Inventory::interactByName(ctx, name, action) → bool srs.inventory.interactByName(name, action) → bool
    Drop all by id Inventory::dropAll(ctx, id) → int32 srs.inventory.dropAll(id) → int
    Drop all by name Inventory::dropAll(ctx, name) → int32 srs.inventory.dropAll(name) → int

    action is the exact menu-option string (e.g. "Eat", "Drop", "Wield", "Bury", "Drink", "Use"). Returns false on any of: slot out of range, slot empty, action not in the opcode table, slot widget not currently rendered, or spoofer failure.

    dropAll returns the number of drops queued. Each drop fires its own DoAction on the next render frame the slot is visible — most callers will run dropAll once per game tick.

    Types¶

    InventoryItem (read-only):

    Field Type Notes
    id int32 OSRS item id; ≤ 0 means empty slot
    quantity int32 Stack qty
    slot int32 0..27

    Example¶

    using namespace srs::api;
if (Inventory::isFull(ctx)) {
    Inventory::dropAll(ctx, "Bones");
}
Inventory::interactByName(ctx, "Lobster", "Eat");

    if srs.inventory.isFull() then
    srs.inventory.dropAll("Bones")
end
srs.inventory.interactByName("Lobster", "Eat")
