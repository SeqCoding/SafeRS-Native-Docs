    Settings¶

    srs::api::Settings / srs.settings

    Read game settings via varbits / varps / varc. The toggle (write) side requires a widget-id table per setting; this module currently exposes only the read half plus a few named convenience helpers.

    Raw reads¶

    Each reader has a "soft" variant (0 / -1 on miss) and a "present?-aware" variant (returns optional / nil).

    Method C++ Lua
    Raw varbit (0 on miss) Settings::varbit(ctx, id) → int32 srs.settings.varbit(id) → int
    Varbit, present?-aware Settings::tryVarbit(ctx, id) → optional<int32> srs.settings.tryVarbit(id) → int \| nil
    Raw varp Settings::varp(ctx, id) → int32 srs.settings.varp(id) → int
    Varp, present?-aware Settings::tryVarp(ctx, id) → optional<int32> srs.settings.tryVarp(id) → int \| nil
    Raw varc int (-1 on miss) Settings::varcInt(ctx, id) → int32 srs.settings.varcInt(id) → int
    Varc, present?-aware Settings::tryVarcInt(ctx, id) → optional<int32> srs.settings.tryVarcInt(id) → int \| nil

    The varc getter already returns -1 as its "missing or wrong type" sentinel, so the raw variant gives -1 for both "not wired" and "unset".

    Named convenience¶

    Populated as widget/varbit IDs are confirmed against RuneLite. Conservative defaults (false / 0) when unresolved.

    Method C++ Lua
    Shift-drop enabled Settings::isShiftDropEnabled(ctx) → bool srs.settings.isShiftDropEnabled() → bool
    Roofs hidden Settings::areRoofsHidden(ctx) → bool srs.settings.areRoofsHidden() → bool
    Run-toggle on Settings::isRunEnabled(ctx) → bool srs.settings.isRunEnabled() → bool
    Current spellbook Settings::spellbook(ctx) → int32 srs.settings.spellbook() → int

    spellbook() returns the varbit 4070 value:

    Value Spellbook
    0 Standard
    1 Ancient
    2 Lunar
    3 Arceuus
