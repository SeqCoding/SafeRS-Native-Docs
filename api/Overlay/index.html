    Overlay¶

    srs::api::Overlay / srs.overlay

    Themed HUD kit layered on Drawing: dark-glass panels, per-skill accent colors, tinted icons, XP rows, animated bars, and level rings. Every call is valid only inside IScript::onDraw / script.draw(fn) — the host drives the frame clock and fonts.

    onDraw-only

    Calling any srs.overlay.* function outside a script.draw(fn) callback (or IScript::onDraw for C++ plugins) is undefined — there is no live ImGui frame. The host calls installFonts / newFrame / clearIconCache itself; scripts never need to.

    Methods¶

    Lua names are snake_case; C++ names are camelCase.

    Method C++ Lua
    Skill accent color Overlay::skillColor(skill) → Color srs.overlay.skill_color(skillInt) → Color
    Skill default icon Overlay::skillIcon(skill) → Icon srs.overlay.skill_icon(skillInt) → int
    Set Custom accent/icon Overlay::setCustom(accent, icon = Icon::Default) srs.overlay.set_custom(color[, icon=Default])
    Register fonts (host) Overlay::installFonts() —
    Frame clock + animation step (host) Overlay::newFrame(dt = -1.0f) srs.overlay.new_frame([dt=-1])
    Drop icon GPU textures (host) Overlay::clearIconCache() —
    Session runtime string Overlay::runtime(seconds = -1.0) → const char* srs.overlay.runtime([seconds=-1]) → string
    Humanized number Overlay::shortNum(value) → const char* srs.overlay.short(v) → string
    Begin themed panel Overlay::beginPanel(id, title, accent) → bool srs.overlay.begin_panel(id, title, skillInt) → bool
    End panel Overlay::endPanel() srs.overlay.end_panel()
    Begin inner card Overlay::beginCard(id = nullptr) → bool srs.overlay.begin_card([id]) → bool
    End card Overlay::endCard() srs.overlay.end_card()
    Next widget on same row Overlay::sameRow() srs.overlay.same_row()
    Vertical gap Overlay::gap(px = -1.0f) srs.overlay.gap([px=-1])
    Pulsing status dot + text Overlay::statusDot(accent, text) srs.overlay.status_dot(skillInt, text)
    Uppercase caption Overlay::label(text) srs.overlay.label(text)
    Icon + label + value row Overlay::statRow(accent, label, value, icon = Icon::Default) srs.overlay.stat_row(skillInt, label, value[, icon=Default])
    Animated progress bar Overlay::bar(accent, pct, height = -1.0f) srs.overlay.bar(skillInt, pct[, h=-1])
    Full XP block row Overlay::xpRow(const XpBlock& b) srs.overlay.xp_row{skill=, name=, gained=, rate=, level_from=, level_to=, pct=}
    Labelled chip (mini bar + %) Overlay::chip(accent, label, pct) srs.overlay.chip(skillInt, label, pct)
    Icon + text chip Overlay::chipText(accent, icon, text) srs.overlay.chip_text(skillInt, iconInt, text)
    Big level ring Overlay::ring(accent, pct, centerBig, centerLabel, diameter = 138.0f, thickness = 11.0f) srs.overlay.ring(skillInt, pct, bigText, labelText[, d=138[, th=11]])
    Compact ring chip Overlay::ringChip(accent, name, pct, sub, icon = Icon::Default) srs.overlay.ring_chip(skillInt, name, pct, sub[, icon=Default])
    Begin N-column grid Overlay::beginGrid(columns) srs.overlay.begin_grid(cols)
    End grid Overlay::endGrid() srs.overlay.end_grid()
    • begin_panel / end_panel and begin_card / end_card must always pair — call the end_* regardless of the begin_* return value (same contract as ImGui windows).
    • set_custom sets the accent (and optional icon) used by Skill.Custom; it persists until changed.
    • runtime returns "HH:MM:SS"; pass seconds < 0 to use the internal session accumulator. In C++ the returned pointer is only valid until the next call.
    • short humanizes numbers (8420000 → "8.42M", 1438 → "1,438"). short is a fine Lua table key, but some editors/linters prefer the srs.overlay["short"] spelling.
    • bar / chip / ring percentages are in [0, 1]. stat_row auto-dims / and · characters in the value string.
    • gap(px) with px < 0 inserts the standard section gap.

    Constants¶

    Overlay::Skill (srs.overlay.Skill.*) — 18 accent identities:

    Fishing, Hunter, Cooking, Woodcutting, Mining, Agility, Thieving, Slayer, Attack, Strength, Defence, Hitpoints, Ranged, Magic, Prayer, Crafting, GP, Custom

    Not the global Skill enum

    srs.overlay.Skill (18 HUD accent identities, nested Overlay::Skill) is a different enum from the global Skill (24 game skills, see Player). The values do not line up — never pass one where the other is expected.

    Overlay::Icon (srs.overlay.Icon.*) — 24 glyphs:

    fish, sword, skull, axe, tree, pickaxe, footprints, mask, paw, pot, flame, heart, gem, coins, backpack, clock, timer, target, trending, bolt, arrow, bank, vial, Default

    Mixed-case Icon keys

    The Lua Icon table keys are lowercase for the glyphs (srs.overlay.Icon.fish) but capitalized for Default (srs.overlay.Icon.Default). Default means "use the accent skill's default icon". C++ enumerators are all capitalized (Icon::Fish, …, Icon::Default).

    Types¶

    Overlay::XpBlock (C++; Lua passes a plain table to xp_row):

    struct XpBlock {
    Skill skill = Skill::Custom;
    const char* name = nullptr;  // nullptr = use the skill's name
    long long gained = 0;
    long long rate = 0;          // per-hour
    int levelFrom = 0;
    int levelTo = 0;
    float pct = 0.0f;            // progress to next level [0,1]
};

    The Lua table keys differ for two fields: level_from / level_to (snake_case), plus skill, name, gained, rate, pct.

    Example¶

    // Inside IScript::onDraw
using namespace srs::api;
if (Overlay::beginPanel("wc_hud", "Woodcutter", Overlay::Skill::Woodcutting)) {
    Overlay::statusDot(Overlay::Skill::Woodcutting, "Chopping");
    Overlay::statRow(Overlay::Skill::GP, "Profit", Overlay::shortNum(184200));
    XpBlock xp;
    xp.skill = Overlay::Skill::Woodcutting;
    xp.gained = 12500; xp.rate = 41000;
    xp.levelFrom = 71; xp.levelTo = 72; xp.pct = 0.34f;
    Overlay::xpRow(xp);
}
Overlay::endPanel();  // always, regardless of beginPanel result

    script.draw(function()
    local S = srs.overlay.Skill
    if srs.overlay.begin_panel("wc_hud", "Woodcutter", S.Woodcutting) then
        srs.overlay.status_dot(S.Woodcutting, "Chopping")
        srs.overlay.stat_row(S.GP, "Profit", srs.overlay.short(184200))
        srs.overlay.xp_row{
            skill = S.Woodcutting, gained = 12500, rate = 41000,
            level_from = 71, level_to = 72, pct = 0.34,
        }
    end
    srs.overlay.end_panel()  -- always, regardless of begin_panel result
end)

    See Drawing for the low-level primitives (srs.draw.*) this kit is built on — anchored overlays, raw draw-list shapes, and input widgets (buttons, sliders, checkboxes).
