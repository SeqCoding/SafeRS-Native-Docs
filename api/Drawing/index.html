    Drawing¶

    srs::api::Drawing / srs.draw

    Overlay drawing.

    onDraw only

    Only valid inside IScript::onDraw (C++) or script.draw(fn) (Lua). The host guarantees a live in-game ImGui frame there; calling from pulse / onTick will fault on builds where those paths run off-frame.

    Anchoring¶

    Pin overlays to OSRS widgets so they follow tab switches and layout mode changes.

    Method C++ Lua
    Live widget rect (cached) Drawing::widgetRect(ctx, g, c) → optional<Rect> srs.draw.widgetRect(g, c) → Rect \| nil
    Compute pinned screen position Drawing::anchorToWidget(ctx, g, c, corner, dx?, dy?, pivot?) → optional<Vec2> srs.draw.anchorToWidget(g, c, corner, dx?, dy?, pivot?) → Vec2 \| nil
    Evict cached rects Drawing::clearAnchorCache() srs.draw.clearAnchorCache()

    Anchor miss policy

    anchorToWidget / widgetRect return the last seen rect for that (group, child) pair when the widget isn't drawn this frame. This keeps overlays pinned through brief widget flicker (tab switches, loading frames). Call clearAnchorCache() on logout or layout mode change to evict.

    Window lifecycle¶

    Method C++ Lua
    Open overlay at pos Drawing::beginOverlay(name, pos, pivot=TopLeft, bgAlpha=0.55) → bool srs.draw.beginOverlay(name, pos, pivot?, bgAlpha?) → bool
    One-call: anchor + begin Drawing::beginAnchoredOverlay(ctx, name, g, c, corner, dx?, dy?, pivot?, bgAlpha?) → bool srs.draw.beginAnchoredOverlay(name, g, c, corner, dx?, dy?, pivot?, bgAlpha?) → bool
    Close overlay Drawing::endOverlay() srs.draw.endOverlay()

    Pair every begin* that returns true with one endOverlay. beginAnchoredOverlay returns false when the widget has never been seen (no cached rect either); in that case do NOT call endOverlay.

    Layout¶

    All identical between C++ and Lua:

    Method Notes
    separator() Horizontal rule
    sameLine(spacing=-1) Stay on same line (negative = ImGui default)
    spacing() Insert vertical gap
    newLine() Force newline
    indent(w=0) / unindent(w=0) Indent / unindent
    dummy(Vec2) Reserve blank space

    Text¶

    Method C++ Lua
    Plain text text(str) (overloads for const char* / std::string) srs.draw.text(str)
    Colored textColored(Color, str) srs.draw.textColored(color, str)
    Bulleted bulletText(str) srs.draw.bulletText(str)

    Interactive widgets¶

    C++ takes a pointer to mutate the value in place; Lua returns a (changed, newValue) tuple since it lacks pointer semantics.

    Method C++ Lua
    Button button(label, size={0,0}) → bool srs.draw.button(label, size?) → bool
    Small button smallButton(label) → bool srs.draw.smallButton(label) → bool
    Checkbox checkbox(label, bool*) → bool (changed) srs.draw.checkbox(label, value) → (changed, newValue)
    Slider int sliderInt(label, int*, vMin, vMax) → bool srs.draw.sliderInt(label, value, vMin, vMax) → (changed, newValue)
    Slider float sliderFloat(label, float*, vMin, vMax) → bool srs.draw.sliderFloat(label, value, vMin, vMax) → (changed, newValue)
    Progress bar progressBar(fraction, size={-1,0}, overlay=nullptr) srs.draw.progressBar(fraction, size?, overlay?)

    Lua idiom for stateful widgets:

    local changed, v = srs.draw.checkbox("Enable", v)
if changed then onToggle(v) end

    Foreground draw list¶

    Always-on-top primitives; no window needed. Coordinates are screen-space. Safe to call from onDraw at any time.

    Method C++ Lua
    Line drawLine(a, b, color, thickness=1) srs.draw.drawLine(a, b, color, thickness?)
    Rect outline drawRect(rect, color, rounding=0, thickness=1) srs.draw.drawRect(rect, color, rounding?, thickness?)
    Filled rect drawFilledRect(rect, color, rounding=0) srs.draw.drawFilledRect(rect, color, rounding?)
    Circle drawCircle(center, radius, color, segments=0, thickness=1) srs.draw.drawCircle(center, radius, color, segments?, thickness?)
    Text drawText(pos, color, str) srs.draw.drawText(pos, color, str)

    Types¶

    Type C++ Lua
    2D point Vec2 { float x, y } srs.Vec2.new(x, y)
    Rectangle Rect { int32 x, y, w, h } read-only srs.Rect (returned by widgetRect)
    Color Color { float r, g, b, a } srs.Color.new(r, g, b, a)
    Corner enum Drawing::Corner { TopLeft, TopRight, BottomLeft, BottomRight, Center } srs.Corner.TopLeft etc.

    Color presets¶

    srs::api::colors::* / srs.colors.*:

    White, Black, Gray, Red, Green, Yellow, Orange, Cyan, Magenta.

    Example¶

    void MyPlugin::onDraw(const ScriptContext& ctx) {
    using namespace srs::api;
    // Window 4 px above chatbox top-left.
    if (Drawing::beginAnchoredOverlay(ctx, "##my-overlay",
                                      162, 0,
                                      Drawing::Corner::TopLeft, 0, -4)) {
        Drawing::textColored(colors::Orange, "Barbarian Fishing");
        Drawing::separator();
        Drawing::text("Mode: Drop fish");
        Drawing::sameLine();
        Drawing::textColored(colors::Yellow, "Tick: 3-tick");
        Drawing::endOverlay();
    }
}

    script.draw(function()
    if srs.draw.beginAnchoredOverlay(
            "##my-overlay", 162, 0,
            srs.Corner.TopLeft, 0, -4) then
        srs.draw.textColored(srs.colors.Orange, "Barbarian Fishing")
        srs.draw.separator()
        srs.draw.text("Mode: Drop fish")
        srs.draw.sameLine()
        srs.draw.textColored(srs.colors.Yellow, "Tick: 3-tick")
        srs.draw.endOverlay()
    end
end)
