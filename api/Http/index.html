    Http¶

    srs.http

    Make HTTPS requests to an external API. Scripts have no network access by default: a script must first authorize with a network key, and the SafeRS server decides whether that key is valid for that script.

    • SDN scripts use the network key issued for their plugin after an admin has reviewed and approved the plugin's network access. A plugin's key works only for that plugin — not in any other script, even if copied or leaked.
    • Local scripts (loaded from your own Scripts folder) use the shared local key. It never works for SDN scripts, and a plugin's key never works for a local script.

    To request network access for your plugin, open it in the Scripter panel and describe what it sends and to which hosts. An admin reviews the request and issues the key. By default an approval covers the build that was reviewed; a new release needs re-approval before network access works again.

    Methods¶

    Method Lua
    Authorize this script with its network key srs.http.authorize(key)
    Authorization state + reason srs.http.status() → state, message?
    Origins this script may call (once granted) srs.http.allowed() → {string}?
    Start a request srs.http.request(opts) → HttpRequest?, err?
    Start a GET srs.http.get(url, headers?) → HttpRequest?, err?
    Start a POST srs.http.post(url, body?, headers?) → HttpRequest?, err?

    authorize returns at once; the check runs in the background. status() returns "none", "pending", "granted" or "denied" (with a reason). Requests made while authorization is pending wait for it, then run or fail.

    Requests never block the script. Each call returns a handle immediately (or nil plus a reason when the request is refused before it starts); poll the handle from onTick, pulse or srs.waitUntil.

    Types¶

    Request options (srs.http.request):

    Field Type Default Notes
    url string — Required. Must be https:// and in the script's approved origins
    method string "GET" GET, POST, PUT, PATCH, DELETE — and allowed by the grant
    headers {[string]: string} none Host, Content-Length, Connection, Proxy-* and similar are refused
    body string "" Sent as-is; set Content-Type yourself
    timeout integer 15000 Milliseconds, 1000–30000

    HttpRequest (the handle):

    Method Lua
    Finished (success or failure) req:done() → boolean
    "authorizing", "queued", "running" or "done" req:state() → string
    Finished with a 2xx status and no error req:ok() → boolean
    HTTP status (0 on a transport error) req:status() → integer
    Response body once done req:body() → string?
    Failure reason req:error() → string?
    One response header (case-insensitive) req:header(name) → string?
    All response headers (lowercased names) req:headers() → table
    Abandon the request req:cancel()

    Limits¶

    • HTTPS only, to a host name (never an IP address or a local name such as localhost). Hosts that resolve to a private or local address are refused.
    • Approved origins only. The URL's https://host[:port] must be one the admin approved for this plugin. The local key allows any public host.
    • Redirects are not followed. A 3xx is returned to the script as-is.
    • No cookies are kept and Windows credentials are never sent.
    • Request body size, response size and requests per minute are set per plugin by the admin (defaults: 16 KB up, 1 MB down, 30 requests/minute).
    • At most 8 requests per script at once.
    • Access can be revoked by an admin at any time. It stops within a few minutes; after that status() is "denied" and new requests are refused.

    Example¶

    local NET_KEY = "srsnet_..."   -- the key issued for this plugin

srs.http.authorize(NET_KEY)

local pending

function script.onTick()
    if not pending then
        local req, err = srs.http.get("https://api.example.com/prices/4151",
                                      { Accept = "application/json" })
        if not req then
            log.warn("price lookup refused: " .. err)
            return
        end
        pending = req
    elseif pending:done() then
        if pending:ok() then
            log.info("price: " .. pending:body())
        else
            log.warn("price lookup failed: " .. (pending:error() or pending:status()))
        end
        pending = nil
    end
end

    Treat your key as public

    Anything in a script can be read by the people running it. A key only works for your plugin, so a copied key does no harm elsewhere — but never put secrets for your own service (its API keys or passwords) in a script. Authenticate per user, or only call endpoints that are safe to expose.
