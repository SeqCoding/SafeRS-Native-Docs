    Spells¶

    srs.spells

    Static metadata for OSRS spells. Pure data; casting logic lives in Magic.

    The table covers 50 Standard-book spells (the 20 strike → surge combat spells, alchemy and other utility spells, 8 teleports, and the NPC / ground-item target spells), the 16 Ancient Magicks combat spells, and the full Lunar (44) and Arceuus (44) books. Standard-book spells other than those listed are not populated, and the Ancient book's non-combat spells (teleports, etc.) are not in the table.

    Methods¶

    Method Lua
    Spell metadata srs.spells.info(s) → SpellInfo
    Lookup by name srs.spells.byName(name) → SpellInfo \| nil
    Enum lookup by name srs.spells.idByName(name) → int \| nil
    All spells in a book srs.spells.inBook(book) → table

    byName / idByName are case-insensitive: an exact name match wins, otherwise the first substring match in table order is returned (so "Strike" resolves to Wind Strike). info returns an empty record (name == "") for a value outside the table. inBook returns every populated entry for that book (Standard 50, Ancient 16, Lunar 44, Arceuus 44). byName returns the metadata record; idByName resolves the Spell enum value itself, ready to feed into srs.magic.cast / srs.magic.canCast.

    Use idByName for casting, byName for metadata

    srs.spells.byName returns a SpellInfo (metadata), not a Spell enum — so idByName is the name → enum path for casting: it returns the Spell enum value srs.magic.cast / srs.magic.canCast take, or nil if nothing matches.

    Spell (srs.spell.*)¶

    Combat (Standard) — 20 strike → surge spells:

    WIND_STRIKE, WATER_STRIKE, EARTH_STRIKE, FIRE_STRIKE, WIND_BOLT, WATER_BOLT, EARTH_BOLT, FIRE_BOLT, WIND_BLAST, WATER_BLAST, EARTH_BLAST, FIRE_BLAST, WIND_WAVE, WATER_WAVE, EARTH_WAVE, FIRE_WAVE, WIND_SURGE, WATER_SURGE, EARTH_SURGE, FIRE_SURGE.

    Utility:

    LOW_ALCHEMY, HIGH_ALCHEMY, BONES_TO_BANANAS, BONES_TO_PEACHES, SUPERHEAT.

    Teleports:

    HOME_TELEPORT, VARROCK_TELEPORT, LUMBRIDGE_TELEPORT, FALADOR_TELEPORT, CAMELOT_TELEPORT, ARDOUGNE_TELEPORT, WATCHTOWER_TELEPORT, TROLLHEIM_TELEPORT.

    NPC / ground-item targets (for srs.magic.castOnNpc / castOnGroundItem):

    TELEKINETIC_GRAB (ground item), CONFUSE, WEAKEN, CURSE, BIND, SNARE, ENTANGLE, STUN, VULNERABILITY, ENFEEBLE, CRUMBLE_UNDEAD, IBAN_BLAST, MAGIC_DART, SARADOMIN_STRIKE, CLAWS_OF_GUTHIX, FLAMES_OF_ZAMORAK, TELEPORT_BLOCK (player target — no cast helper yet).

    The Ancient, Lunar and Arceuus constants are listed per book below. The Target column says which Magic call drives the spell: NPC → castOnNpc, Inventory item → castOnInventory, Self / none → cast. Player-target spells have no cast helper yet (castOnNpc does not apply). All books share spellbook widget group 218; the book must be the active one for the spell to be clickable.

    Rune costs are the plain wiki costs. canCast counts runes in the inventory and rune pouch, accepts combination runes (mist, dust, smoke, mud, steam, lava) for their elements, and treats a worn elemental staff, battlestaff or tome (weapon / shield slot) as an unlimited supply of its elements. Other staff substitution (Iban's staff, slayer staff, god staves) is not modelled, so canCast reports false for Iban Blast / Magic Dart / the god spells unless the base runes are carried. Non-rune reagents (bones, ashes, ensouled heads, logs, etc.) are not modelled either.

    Types¶

    SpellInfo (read-only):

    Field Type Notes
    name string Canonical display name
    level integer Magic level required
    book integer (srs.spellbook.*) See above
    widgetGroupId integer Spellbook widget group
    widgetChildId integer Child id within group
    iconItemId integer UI / identification (-1 if N/A)
    runes table of RuneCost Per-cast rune cost

    RuneCost (read-only):

    Field Type
    runeItemId integer
    count integer

    Example¶

    -- Name → enum for casting:
local s = srs.spells.idByName("High Level Alchemy")
if s and srs.magic.canCast(s) then
    srs.magic.cast(s)
end

-- Metadata via the srs.spell.* constants:
local info = srs.spells.info(srs.spell.HIGH_ALCHEMY)
log.info(("%s needs Magic %d"):format(info.name, info.level))
for _, cost in ipairs(info.runes) do
    log.info(("  rune %d x%d"):format(cost.runeItemId, cost.count))
end

-- Every spell in a book (real 1-based table):
for _, sp in ipairs(srs.spells.inBook(srs.spellbook.ANCIENT)) do
    log.info(("%s (Magic %d)"):format(sp.name, sp.level))
end
