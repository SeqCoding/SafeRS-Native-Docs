    NPC¶

    srs::api::Npc / srs.npc

    Per-NPC actions. The target is an ActionTarget — usually obtained from the entity query API (entityQuery) or other facade returns. The ActionTarget carries the spawn index and world coords that DoAction needs.

    All interact / attack / talkTo / bank calls route through Interact, which always spoofs mouse motion + click before DoAction (no escape hatch).

    Methods¶

    Method C++ Lua
    Generic interact Npc::interact(ctx, target, action) → bool srs.npc.interact(target, action) → bool
    Attack Npc::attack(ctx, target) → bool srs.npc.attack(target) → bool
    Talk-to Npc::talkTo(ctx, target) → bool srs.npc.talkTo(target) → bool
    Bank (banker NPCs) Npc::bank(ctx, target) → bool srs.npc.bank(target) → bool
    Still in world map Npc::isAlive(ctx, target) → bool srs.npc.isAlive(target) → bool

    action is the exact menu-option string the game shows ("Attack", "Talk-to", "Bank", "Pickpocket", "Trade", "Steal-from", …).

    isAlive semantics

    isAlive is a host-side check that the NPC's NpcInstance is still present in the world hash map. After an NPC dies it lingers a few ticks playing the death animation, then despawns — once that happens isAlive returns false. Currently does not treat HP-0-but-still-rendering as "dead"; callers that need that (loot timing, drop tracking) should poll currentHp via the NPCs panel column or entity.npcById(...).

    ActionTarget method-call shortcuts (Lua)¶

    The ActionTarget usertype exposes the same set as methods:

    local npc = entity.nearestNpc()
if npc and npc:isAlive() then
    npc:attack()         -- == srs.npc.attack(npc)
    npc:talkTo()
    npc:bank()
    npc:interact("Pickpocket")
end

    ActionTarget fields¶

    Read-only:

    Field Notes
    kind TargetKind enum (None / Npc / Player / Object / Tile)
    tileX, tileY, tileZ World tile coords
    plane 0..3
    spawnIndex Server-assigned spawn index
    entityId Item/Loc/Npc id depending on kind
    name Display name
    currentHp, maxHp Live HP — see Project Status notes on boss scale
    interactTarget Server-side target index (-1 = none)
    animationId Active anim id
    isValid() Method, returns bool

    Example¶

    using namespace srs::api;
auto npc = ctx.entityQuery->nearestNpc();
if (npc && Npc::isAlive(ctx, *npc)) {
    Npc::attack(ctx, *npc);
}

    local npc = entity.nearestNpc()
if npc and npc:isAlive() then
    npc:attack()
end
